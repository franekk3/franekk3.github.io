How to install PWA

Android
iOS/iPadOS
Desktop

Note: For Android you can use most Chromium-based browsers, but for best experience Google Chrome is recomended to use. Also some of the newest versions of the Firefox might work.

Installing PWA on Android,
1. Open your Browser and go to the web site wich you want to install,
2. Click ⋮ in top right corner, then find "Install and create shortcut" option and click it and then "Install".
3. App should apear on your home screen in about a minute.

Note: For iOS and iPadOS you need to use Safari browser due to the Apple's limitations.

Installing PWA on iOS,
1. Open Safari and go to the web site wich you want to install,
2. Click icon, then scroll to "Add to home screen" option, click it. And then Add in top right corner.
3. Close Safari, app should apear on the home screen in a second.

Note: For Desktop you need to use any Chromium Based browser (Firefox on Desktop doesn't support PWA) or Safari on MacOS.

Installing PWA on Desktop,
1. Open your browser,
2. Click icon, then find to "Cast, save and share" option, click it. And then select Install and the same on the popup.
3. App should apear on the home screen and lunch automaticly.
